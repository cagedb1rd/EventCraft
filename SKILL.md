# EventCraft

Use this existing executable project. Install with `python -m pip install -e <skill-directory>` and `python -m playwright install chromium` if needed. Run from the skill directory or use absolute paths. Read [the event contract](references/event-schema.md), [workflow](references/workflow.md), and [host image workflow](references/image-generation.md).

1. Understand event text/files using Agent capabilities or `eventcraft extract <input>`. Save evidenced facts to `event.json`. Never invent dates, venue, organizer, speakers, fees or registration. Record unknowns/conflicts; ask one combined question for essential missing fields and confirm an IANA timezone. Do not finish unresolved facts unless producing an explicitly requested marked `--draft`.
2. Unless style/automatic selection was already requested, run `eventcraft recommend event.json --output <state-dir>`. Display the current **three actual PNG previews** with reasons/tradeoffs. Accept 1/2/3, automatic choice, another batch or a reference. Previews use bundled original image_gen artwork, labeled reusable. Preserve state; numbers refer to the current list. `--next` gives a disjoint batch; show all ten only on request.
3. Honor the selected style. Read its [design guide](references/style-guides/). For a custom reference, **actually inspect the image** using vision/view_image, record composition/material/typography observations in `event.style_description`, and create original artwork. Do not embed or copy reference images. `--style-reference` remains available for local palette analysis/replay; palette-only is not visual understanding. After changing event facts/direction, regenerate recommendation state before resolving numbered choices.
4. Discover the current host's available tools and read its imagegen skill if available. Do not assume a tool name or destination argument. Prefer the actual built-in `image_gen` tool without an API key. Run `eventcraft art-plan event.json --style <id> --output <private-work>/art-plan.json`; read its semantic context, font contract and normalized composition zones, then **actually invoke the available built-in image tool with its prompt**. Every new event needs a new concept and call; the ten styles specify media, type and layout, never fixed subjects. A plan is not a generated asset. Generate original text-free art with natural quiet title/fact areas; the renderer owns lettering and QR. Actually view the image; reject imagery unrelated to the title/subtype/keywords or with busy reading zones. Correct the concept/composition and regenerate before adding panels. For ratio-sensitive scenes, prepare a separate `--ratio square` or `--ratio print` plan and call again; save variant receipt paths in `assets.visual_variants`. Never crop away the planned negative space.
5. Import the real returned image: `eventcraft art-import <plan> --image <real-generated-file> --output <private-work>/art-v1 --generator codex-imagegen`. This copies it into the project and creates a facts/style/hash receipt. Never fabricate a receipt or claim a call occurred. The receipt is host-agent attested, not independent proof of tool execution. If image_gen is absent/fails, report the actual limitation; bundled original art can provide an explicitly described reusable-art result. Never pretend a fresh call succeeded or silently use a paid API. Paid fallback requires explicit authorization.
6. Execute **one** `eventcraft all event.json --select 2 --state <state-dir> --visual-receipt <art-v1>/receipt.json --require-art --output <campaign-dir>` (or `--style <id>` / `--auto-style`). Do not mutate `event.json` just to add the receipt before numbered selection. The package includes portrait/square/A4 posters, a **visual invitation PNG and print PDF**, a text letter, copy, editable sources, preview and manifest.
7. Invitation form is automatic from activity/formality/style: Boarding Pass, Ticket Stub, Formal Invitation Card or Folded Invitation. Honor `--invitation-format` when specified. Boarding passes have a body/stub/perforation/design number; tickets have tear lines and ticket structure; formal cards have ceremonial type/paper/frame; folded output includes exterior/interior PNGs and a two-page print PDF. Design numbers are not admission credentials. Share poster art/palette with a distinct composition.
8. **Posters contain only** title, one short supplied subtitle/slogan, natural date/time, location and optional explicitly useful CTA, QR or organizer/logo. Omit bullets, raw URLs, fee/deadline blocks, repeated facts, filler and introductions. Do not invent a slogan or CTA to fill space. Detailed invitations and copy retain facts. Readability comes from the generated scene's natural negative space and style-specific type placement; **opaque rectangular title/fact/footer plates are forbidden as the default remedy**. Color geometry is allowed as intentional Swiss/Brutalist/Retro art direction. Move lettering, regenerate artwork or use subtle integrated light transitions when needed. `show_timezone=false` hides internal timezone identifiers; display a user-facing label only when requested or necessary for a cross-zone event. QR is optional: `qr_policy=auto` generates only for explicit scan instructions; `show` requires a valid URL, `hide` suppresses it. No QR placeholders. Commercial fonts are never bundled; manifest records actual platform fallback fonts.
9. Inspect final PNGs, including all ratios and invitation form, plus PDF page renders. `manifest.json` includes DOM bounds, actual fonts and actual background contrast samples under text; a flagged sample requires visual review and correction, not a false acceptance claim. Samples and unit tests alone cannot certify design. At least one inspection/correction/rerender loop is required for a new design system or when a defect is found. Report actual generation mode, paths, checks and limits. Demos/drafts are marked and not publishable. Never insert demo labels into a real event. If the host cannot generate, explicitly report unavailable/failed generation and describe the reusable-art fallback before proceeding; never claim fresh AI generation or switch to a paid API without authorization.

Multi-size export, references, selection/next/auto, asset preservation and conservative copy remain supported. `eventcraft gallery` renders all ten systems and four invitation formats. Never autonomously upload/publish materials. Keep private event data, third-party references, credentials and working output out of distributable assets. `/image/` is research-only and excluded from Git and packaging.
