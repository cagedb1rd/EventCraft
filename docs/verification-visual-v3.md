# EventCraft v3 本地验收

验收日期：2026-10-12，Australia/Sydney。所有活动数据明确为虚构；本次没有 push、PR、Release、仓库创建或任何远程发布，没有使用付费 API 或 API Key。

## 改动与正式运行机制

- 保留现有抽取、缺失/冲突确认、十风格三选一/自动/换批/参考、自定义样式、一次整套文案与多尺寸导出。新代码沿用同一公开 CLI/renderer；验收脚本没有另一套演示渲染器。
- `visuals.py` 的 v3 brief 包含活动标题、类别/子类、关键词、受众、方向与艺术媒介；不再固定人脸、音乐人、跑者或甲虫主题。凭据继续绑定真实图像字节、活动与风格，并兼容已有 v1 凭据。
- `composition.py` 在生成前按标题长度与输出比例计算自然标题/信息/CTA 预留区；同一坐标指导图像生成与文字排版。比例素材用 `assets.visual_variants`，导出后可相对路径迁移重放；错误比例被拒绝。
- `typography.py` / `typography.json` 和十套公开指南定义中文/英文标题、信息、副标题、数字、字重、字距、行高、对齐、中文标点/短语及混排规则。真实字宽测量计入字距；manifest 记录实际字体。没有复制字体文件。
- 海报文字区域透明，默认没有标题矩形、日期色条或页脚底板。实际背景采样会在既定留白区内比较顶部/中部/底部对齐；无法解决则由 Agent 重构图/生成，不能用采样代替视觉判断。
- 日期和截止时间自然格式化，默认隐藏内部时区。链接不自动触发 QR；明确扫码意图或 `qr_policy=show` 才产生。没有二维码时不留框。过长副标题留在详细邀请函/文案，海报不显示长介绍或虚构 CTA。
- 四种视觉邀请函有独立票据/纸张/折页结构、PNG 与 PDF；折页包括内外展开和两页打印文件。

安装 Skill 后，宿主 Agent 先发现实际工具、运行 `art-plan`，读取活动/构图/字体契约，**调用当次可用内置 image_gen**，实际查看图像，再 `art-import` 与 `all --require-art`。Python CLI 不具备调用聊天工具的权限；该宿主编排由 SKILL.md 明确执行。没有内置工具时如实报告，后备素材记录 `reusable-art-fallback`，不得冒充新生成或自动收费。

## 实际问题、修复与复查

1. 科技竖图居中裁方图把标题与时间压在玻璃高光上：发现成品后真正重新生成方形构图，并引入比例素材/完整原图适配，重渲染后可读。
2. 长标题通过 DOM 但遮住主体：真正重新生成上部约 55% 自然暗区、较小下部主体的作品，重新查看长中文/英文/混排结果，遮挡解决。
3. 运动初稿偏建筑效果图：重生成粗笔触木刻/橙色速度线作品，重新查看完整海报。
4. Neo 中文字形行框紧、Swiss 分词遗漏负字距：修正对应行高与测量，重新渲染，针对性测试通过。
5. Swiss 小字黑墨不够深：实际采样和视觉检查后使用纯黑设计墨色，重渲染，对比度标记归零。
6. 篮球 QR 原尺寸解码失败：增大至竖图 164px、方图 150px，预留角落并收窄信息区；重渲染后竖图/方图/邀请函均真实解码成功。
7. 隔离 Word 抽取把 `Shanghai` 中的 `ai` 识别为 AI 主题：添加 ASCII 词边界，重新抽取并使用修正后的真实安装计划生成；新增回归通过。
8. PDF 地点文本比对误报警：查看栅格确认字形完整，原因是兼容汉字和 ligature 映射；检查器加 NFKC 规范化。不是以修改检查器掩盖缺字。

## 文件保护与限制

`/image/` 已在 .gitignore，`git ls-files image` 为空。14 张参考的字节哈希与早期库存完全相同。本轮没有删除、重命名、移动或修改参考图；早期 UUID 库存通过哈希匹配当前已有名称，不重新分类。原创生成素材分目录存放。安装包 allowlist 不含 image、私有目录、密钥或字体文件。
