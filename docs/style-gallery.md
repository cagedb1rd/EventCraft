# Style Gallery

全部由同一固定虚构活动和本项目 Chromium 渲染器产生。点击海报或邀请函可查看原尺寸图。离线页面：[Gallery](../examples/gallery/index.html)。重现：`python scripts/generate_style_gallery.py`。
