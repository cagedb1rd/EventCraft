Every campaign preview links copy, editable HTML, event facts, actual-font/bounds/readability reports and PNG/PDF exports. These artifacts are produced by the same public renderer as the installed Skill, not a separate demo renderer.

The previous v2 Gallery remains in examples/gallery as historical evidence. Its opaque panels and default timezone/QR output are not the current design system. Do not use previous validation counts for v3.
