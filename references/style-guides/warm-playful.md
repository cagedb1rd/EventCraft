# 温暖手绘风 / Warm playful

定位：organic。适用：birthday, workshop, community, market, wedding。这是一套原创布局，网络参考仅用于原则研究。

## Tokens 与字体

背景 `#fff3db`，正文 `#4e392b`，强调 `#a84b36`。采用系统无衬线字体；中文分别回退 Microsoft YaHei / Noto Sans CJK SC 或 SimSun / Noto Serif CJK SC。系统字体不进入仓库。
标题字体栈：`KaiTi, Kaiti SC, Noto Serif CJK SC, Georgia`；字重 600。中英文各自回退到可用字体，manifest 记录实际使用结果。温暖风使用系统楷体，保留亲切的书写感。
海报标题上限 148 px，正文 35 px，信息 40 px，标签 24 px；邀请函标题 112 px，方图标题 96 px。1080 宽画布安全边距 72 px（各风格另有轴线与框线边距）。实际字体尺寸由 Chromium 度量，优先压缩装饰空间，再根据可用区域收缩，达到下限仍溢出则失败。

## 构图与成套适配

海报：顶部手绘枝叶 / 便笺式标题 / 花朵太阳插画 / 圆角邀请信纸。
邀请函：短花边与亲切称谓，正文纸卡占比增加。使用相同颜色、图案和字体，在 1080×1350 上重排正文，不裁切竖版。
方图压缩图形区并减少标题上限；A4 重新采用邀请式版式并在 PDF 中保留矢量文字。

## 适配与负面约束

长标题按真实字宽自动换行，不截断日期地点报名；中英混排使用 `overflow-wrap:anywhere`，英文保持自然词界。可省略可选的视觉副文，但原始信息保留在 event.json 和完整文案中。没有主图仍使用自有 SVG/几何装饰；用户主图、Logo 使用 contain，二维码有白色静区。
按浏览器度量的标题宽度判断短/中/长标题，平衡换行；长标题在瑞士与运动海报中由左右分栏展开为全宽标题，其他风格压缩装饰区。结构先适配，字号再收缩。
避免伪手写中文字与幼稚化正式会议。正文颜色自动调整至对背景至少 4.5:1；品牌禁止色先过滤。图案不可冒充真实徽章或活动事实。

取舍：亲和温暖，正式商务气质较弱。
