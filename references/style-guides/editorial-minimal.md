# 编辑杂志极简风 / Editorial minimal

定位：editorial。适用：exhibition, community, lecture, launch, wedding。这是一套原创布局，网络参考仅用于原则研究。

## Tokens 与字体

背景 `#f6f1e7`，正文 `#242621`，强调 `#627363`。采用系统衬线字体；中文分别回退 Microsoft YaHei / Noto Sans CJK SC 或 SimSun / Noto Serif CJK SC。系统字体不进入仓库。
标题字体栈：`Georgia, SimSun, Noto Serif CJK SC, Songti SC`；字重 400。中英文各自回退到可用字体，manifest 记录实际使用结果。温暖风使用系统楷体，保留亲切的书写感。
海报标题上限 140 px，正文 35 px，信息 40 px，标签 24 px；邀请函标题 112 px，方图标题 96 px。1080 宽画布安全边距 72 px（各风格另有轴线与框线边距）。实际字体尺寸由 Chromium 度量，优先压缩装饰空间，再根据可用区域收缩，达到下限仍溢出则失败。

## 构图与成套适配

海报：杂志刊头 / 偏置作品窗 / 编辑标题 / 页脚细栏。
邀请函：开放式纸面，细线将邀请文字与实用信息分开。使用相同颜色、图案和字体，在 1080×1350 上重排正文，不裁切竖版。
方图压缩图形区并减少标题上限；A4 重新采用邀请式版式并在 PDF 中保留矢量文字。

## 适配与负面约束

长标题按真实字宽自动换行，不截断日期地点报名；中英混排使用 `overflow-wrap:anywhere`，英文保持自然词界。可省略可选的视觉副文，但原始信息保留在 event.json 和完整文案中。没有主图仍使用自有 SVG/几何装饰；用户主图、Logo 使用 contain，二维码有白色静区。
按浏览器度量的标题宽度判断短/中/长标题，平衡换行；长标题在瑞士与运动海报中由左右分栏展开为全宽标题，其他风格压缩装饰区。结构先适配，字号再收缩。
避免高饱和霓虹与厚边框。正文颜色自动调整至对背景至少 4.5:1；品牌禁止色先过滤。图案不可冒充真实徽章或活动事实。

取舍：留白丰富，长议程更适合附页。
