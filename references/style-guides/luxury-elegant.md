# 奢华典雅风 / Luxury elegant

定位：ceremony。适用：wedding, dinner, awards, forum。这是一套原创布局，网络参考仅用于原则研究。

## Tokens 与字体

背景 `#f5f0e5`，正文 `#18392d`，强调 `#876d3c`。采用系统衬线字体；中文分别回退 Microsoft YaHei / Noto Sans CJK SC 或 SimSun / Noto Serif CJK SC。系统字体不进入仓库。
标题字体栈：`Times New Roman, SimSun, Noto Serif CJK SC, Songti SC`；字重 400。中英文各自回退到可用字体，manifest 记录实际使用结果。温暖风使用系统楷体，保留亲切的书写感。
海报标题上限 140 px，正文 35 px，信息 40 px，标签 24 px；邀请函标题 112 px，方图标题 96 px。1080 宽画布安全边距 72 px（各风格另有轴线与框线边距）。实际字体尺寸由 Chromium 度量，优先压缩装饰空间，再根据可用区域收缩，达到下限仍溢出则失败。

## 构图与成套适配

海报：双层细线框 / 精致几何花结 / 衬线主标题 / 中轴留白 / 礼仪信息组。
邀请函：把礼仪称谓置于主标题上，细信息与报名做信笺底栏。使用相同颜色、图案和字体，在 1080×1350 上重排正文，不裁切竖版。
方图压缩图形区并减少标题上限；A4 重新采用邀请式版式并在 PDF 中保留矢量文字。

## 适配与负面约束

长标题按真实字宽自动换行，不截断日期地点报名；中英混排使用 `overflow-wrap:anywhere`，英文保持自然词界。可省略可选的视觉副文，但原始信息保留在 event.json 和完整文案中。没有主图仍使用自有 SVG/几何装饰；用户主图、Logo 使用 contain，二维码有白色静区。
按浏览器度量的标题宽度判断短/中/长标题，平衡换行；长标题在瑞士与运动海报中由左右分栏展开为全宽标题，其他风格压缩装饰区。结构先适配，字号再收缩。
避免金色渐变堆砌、虚假家徽和假主办方 Logo。正文颜色自动调整至对背景至少 4.5:1；品牌禁止色先过滤。图案不可冒充真实徽章或活动事实。

取舍：礼仪感突出，长文本会降低高级留白感。
